# portofolio

My personal portfolio: Python, AI/ML and computer vision projects, with **Habit Garden** (my productivity app) as the featured project.

It's a single static page (`index.html`) with no build step and no dependencies.

## View locally

Open `index.html` in a browser.

## Deploy

- **GitHub Pages:** go to Settings → Pages, set the source to the `main` branch and the `/ (root)` folder. The site goes live at `https://nobraindev-pavan.github.io/portofolio/`.
- **Vercel:** at vercel.com/new, import `nobraindev-pavan/portofolio`, leave Framework Preset as **Other** with no build command, and click **Deploy**. Every push to `main` redeploys.
